# ESP32-Blynk-WiFi-Controlled-Robot-Car
Wi-Fi controlled robot car using ESP32 and Blynk IoT with forward, backward, left, right, stop, and variable motor speed control.

This project is a Wi-Fi controlled robotic car built using an ESP32, motor driver, DC motors, and Blynk IoT. The car can be controlled remotely through the Blynk app, including forward, backward, left, right, stop, and adjustable motor speed.
